# Workout Tracker API

## Project Description

Workout Tracker API is a Flask REST API backend application that allows users to manage workouts and exercises.

The application allows users to:

- Create and view workouts
- Create and view exercises
- Assign exercises to workouts
- Track exercise details such as sets, reps, and duration
- View relationships between workouts and exercises

The project demonstrates the use of Flask, SQLAlchemy, Flask-Migrate, and Marshmallow for building a structured REST API with database relationships, validations, and serialization.
